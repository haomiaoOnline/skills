# 高性价比人生决策 Skill

`life-decision-guide` 是一个基于《高性价比人生指南》的循证人生决策 Skill。

它不是简单复述书中的建议，而是先检索相关证据，再结合现实约束、最坏情况、可逆性、信息价值和个人偏好，帮助回答“该不该做、值不值、怎么选、先做什么、什么时候改变决定”。

正式执行规则见 [SKILL.md](./SKILL.md)。

## 内容边界

这个仓库中的上游快照不是对原项目的整站镜像，只保留会直接参与决策检索和证据追溯的材料：

- 34 个正文章节。
- 5 篇有独立决策价值的核心长文。
- 上游许可证和版本来源信息。
- 论文、法律、政府、法院、疾控等真正支撑结论的证据链接。

以下内容明确不进入本 Skill：

- 商业广告、推广链接和广告图片。
- 微信赞赏码、收款码、打赏入口。
- Star History、仓库宣传组件。
- 上游网页 UI、侧栏、弹窗等展示层代码。
- `引用对照.md` 等内部维护和编辑辅助材料。
- 已确认失效且有现行官方替代来源的旧链接。

因此，外部链接不是一律删除。能直接支撑条目结论的 DOI、法律原文和官方材料属于核心证据，会保留；与决策无关的商业、推广、打赏和展示链接则不会保留。

## 核心能力

- 先查指南证据，再做判断，避免凭记忆编数字、法规或研究结论。
- 输出区分 `[指南]`、`[当前核验]`、`[推理]`、`[偏好]`、`[未知]`。
- 不把寿命、健康、时间、金钱、自由强行压成一个伪精确总分。
- 优先检查硬约束、最坏情况、不可逆风险和退出条件。
- 法律、社保、医保、税务、补贴、签证、价格、政策等时效信息，真实回答时要求重新核验当前官方来源。


实际 Top 1：

| 字段 | 结果 |
| --- | --- |
| 章节 | 第 8 节「别把自己搭进去」 |
| 条目 | 第 18 条 |
| 标题 | 借钱写清借条，替人担保前先想清楚自己愿不愿意替他还 |
| 证据等级 | A |
| 收益口径 | 金钱 |
| 成本标签 | 钱=0、时间=少、毅力=否、收益=大 |

指南备注还明确提醒，要看清担保文本中的具体责任约定，不能把“只是签个字”当作低风险动作。

### 实测效果

这个场景能稳定把问题从“要不要给朋友面子”重构成“如果借款人完全无法还款，我是否愿意并有能力承担可能落到自己身上的债务”。

最终回答阶段应继续检查：

1. 最坏情况是否能承受。
2. 签字后的可逆性。
3. 担保方式和合同具体条款。
4. 为什么需要第三方担保，本身是否反映额外信用风险。
5. 信息不完整时优先“先验证再做”，而不是在人情压力下当天签字。

**验收结果：PASS。** 关键词“担保”直接命中专门条目，没有泛化到普通借钱、友情或投资建议。

### 测试问题

```text
MacBook 延保要多花 1800 元，值不值得买？
```

### 实际检索

```bash
python3 scripts/query_guide.py --limit 1 --full --json 延保
```

实际 Top 1：

| 字段 | 结果 |
| --- | --- |
| 章节 | 第 5 节「不要浪费钱」 |
| 条目 | 第 11 条 |
| 标题 | 拒绝电子产品的延长保修（延保） |
| 证据等级 | B |
| 收益口径 | 金钱 |
| 成本标签 | 钱=0、时间=少、毅力=否、收益=中 |

该条目的备注同时给出重要例外：能自行承担一次维修费的普通消费者，与“只有一台生产设备、没有备用机”的用户不能按同一结论处理。

### 实测效果

Skill 不会机械输出“延保都不值得买”，而会继续检查：

1. 延保价格占设备价格的比例。
2. 一次典型维修是否能自行承担。
3. 设备是不是关键生产工具。
4. 有没有备用机。
5. 停机带来的收入或工作损失。
6. 保障范围、免赔额和除外责任。

因此普通可自保用户通常会偏向“不买”；如果停机会造成明显损失且没有备机，则应转为“先核算具体保障后再决定”。

**验收结果：PASS。** 检索命中准确，且条目备注能阻止把“拒绝延保”过度泛化成绝对规则。

## 用例 3：存款够 10 个月，要不要辞职休息半年

### 测试问题

```text
我现在存款够生活 10 个月，工作很累，要不要辞职休息半年？
```

### 实际检索

```bash
python3 scripts/query_guide.py --limit 1 --full --json 辞职
```

实际 Top 1：

| 字段 | 结果 |
| --- | --- |
| 章节 | 第 19 节「在职离职和工伤」 |
| 条目 | 第 7 条 |
| 标题 | 不要签「个人原因主动辞职」，那一签就没有 N 了 |
| 证据等级 | B |
| 收益口径 | 金钱 |
| 成本标签 | 钱=0、时间=少、毅力=是、收益=大 |

继续检索“辞职”还会命中：

- 第 7 节第 1 条「失业了先在线申领失业保险金」，证据 A。
- 第 29 节第 12 条「变故后的头三个月，凡是不可逆的大决定一律往后推」，证据 C。
- 第 19 节第 9 条「走人之后立刻办两件事：失业登记领失业保险金，看清竞业协议」，证据 C。

### 实测效果

这个用例验证的是“指南证据”和“个人最终决定”是否会被错误混在一起。

指南主要提供离职手续、权益、失业保障和竞业限制相关证据，但并没有直接回答“这个用户现在是否应该辞职半年”。因此最终回答必须分层：

- `[指南]`：列出指南确实覆盖的离职证据。
- `[当前核验]`：涉及当前劳动法、失业保险资格、金额和当地政策时，重新查官方来源。
- `[推理]`：再根据个人现金流、休息目标、就业恢复路径和最坏情况分析。

典型需要继续检查的变量包括：

1. 10 个月存款是否已包含房租、保险、家庭责任和突发支出。
2. 休息半年后还剩多少安全垫。
3. 辞职目标是恢复身体、转行、学习，还是单纯逃离环境。
4. 半年后重新就业的难度和预期收入。
5. 是否存在年假、病假、调岗、降强度或拿到新 offer 后再走等更可逆方案。
6. 如果一年找不到满意工作，是否仍能承受。

最终结论不应伪装成“书里说你应该辞职”，而应落到“做 / 不做 / 先验证再做 / 做一个更小的可逆试验”之一，并说明改变结论的条件。

**验收结果：PASS。** 检索准确，同时能验证证据层与个人决策层必须分离。

## 实测结论

三个场景分别验证了这个 Skill 的三类价值：

- **担保**：识别不可逆、高尾部风险的人情决策。
- **延保**：识别低概率风险是否值得花钱转移，并保留重要例外条件。
- **辞职**：当指南只有局部证据时，不把“相关证据”冒充成“个人最终答案”。

它的目标不是替用户“算命”，而是先排除不可逆的大错，再用证据寻找高性价比动作，最后把真正属于个人价值取舍的部分留给用户决定。
