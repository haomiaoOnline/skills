# 来源与更新策略

## 1. 来源层级

优先级从高到低：

1. 本地快照中条目直接引用的一手论文、法律、政府和官方文件。
2. 当前重新核验的一手官方来源。
3. 高质量学术综述或权威机构材料。
4. 可靠二手报道，仅用于补背景。
5. 论坛、自媒体、短视频和未署名转载，不用于支撑关键结论。

## 2. 本地快照是什么

本 Skill 随包保存《高性价比人生指南》上游仓库的一个固定版本。

查看：

```bash
cat assets/upstream/SOURCE.json
```

固定版本的优点：

- 回答可复现。
- 不会每次读取到不同版本。
- 离线也能检索。

缺点：

- 法律、金额、名单、政策和指南可能过期。

因此，固定快照是“知识基线”，不是“所有当前事实的最终权威”。

## 3. 哪些内容必须关注日期

尤其注意：

- 法律法规和司法解释。
- 医保、社保、补贴、税务。
- 签证、留学、出入境。
- 旅行安全和国家/地区名单。
- 药品政策和医疗指南。
- 产品规则、价格、费率。
- 就业和劳动政策。

回答这些问题时要带上数据或政策日期。

## 4. 冲突处理

如果本地指南与当前一手来源冲突：

1. 先确认是不是适用地区、人群、版本不同。
2. 当前生效的一手来源优先用于当前事实。
3. 明确告诉用户“指南快照中的旧口径是什么、现在核验到的新口径是什么”。
4. 不静默篡改指南原文。
