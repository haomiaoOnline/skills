# 来源与更新策略

## 1. 来源层级

优先级从高到低：

1. 本地快照中条目直接引用的一手论文、法律、政府和官方文件。
2. 当前重新核验的一手官方来源。
3. 高质量学术综述或权威机构材料。
4. 可靠二手报道，仅用于补背景。
5. 论坛、自媒体、短视频和未署名转载，不用于支撑关键结论。

## 2. 本地快照是什么

本 Skill 随包保存《高性价比人生指南》上游仓库的一个固定版本。

查看：

```bash
cat assets/upstream/SOURCE.json
```

固定版本的优点：

- 回答可复现。
- 不会每次读取到不同版本。
- 离线也能检索。

缺点：

- 法律、金额、名单、政策和指南可能过期。

因此，固定快照是“知识基线”，不是“所有当前事实的最终权威”。

### 快照边界

本 Skill 只保存真正参与决策检索的上游内容：

- `book/` 正文章节。
- 经过白名单筛选的 5 篇核心长文：做平台要办哪些证、家庭应急装备清单、生物钟和夜班、结婚划不划算、遇到陌生人出事该不该停。
- `LICENSE` 许可证。
- `SOURCE.json` 来源与版本元数据。

以下上游内容明确不进入 Skill 快照：

- 商业广告及广告图片。
- 微信赞赏码、打赏入口等捐赠内容。
- Star History 等仓库展示组件。
- `index.html` 网页 UI、侧栏、弹窗等展示层代码。
- 上游 `README.md` 的宣传、赞赏、广告等仓库展示内容。
- `docs/引用对照.md` 等上游内部维护、映射和编辑辅助材料。

这些内容与人生决策知识无关，保留它们只会污染 Skill 资产边界。上游来源、署名和许可证信息继续通过 `SOURCE.json`、`LICENSE` 和本文件保留。

## 3. 哪些内容必须关注日期

尤其注意：

- 法律法规和司法解释。
- 医保、社保、补贴、税务。
- 签证、留学、出入境。
- 旅行安全和国家/地区名单。
- 药品政策和医疗指南。
- 产品规则、价格、费率。
- 就业和劳动政策。

回答这些问题时要带上数据或政策日期。

## 4. 冲突处理

如果本地指南与当前一手来源冲突：

1. 先确认是不是适用地区、人群、版本不同。
2. 当前生效的一手来源优先用于当前事实。
3. 明确告诉用户“指南快照中的旧口径是什么、现在核验到的新口径是什么”。
4. 不静默篡改指南原文。
