# 输出协议

## 目录

- Quick
- Standard
- Deep
- 表达要求

## Quick

适合低影响、单一问题。

结构：

1. 一句话结论。
2. 2–4 个关键理由。
3. 成本 / 收益 / 证据等级。
4. 一个下一步动作。
5. 指南出处。

示例骨架：

```text
结论：先不买 / 可以做 / 先验证。

[指南] ...
[推理] ...

代价：
收益：
风险：
下一步：

来源：《高性价比人生指南》第 X 节第 Y 条（...）
```

## Standard

适合大多数人生选择。

```text
结论
- 条件结论，避免假装存在唯一答案。

为什么
1. [指南] ...
2. [当前核验] ...
3. [推理] ...

选项对比
| 维度 | A | B |
| --- | --- | --- |
| 钱 | ... | ... |
| 时间/精力 | ... | ... |
| 主要收益 | ... | ... |
| 最坏情况 | ... | ... |
| 可逆性 | ... | ... |
| 证据 | ... | ... |

建议动作
- 先做什么。
- 暂时不要做什么。
- 如果需要，做什么低成本验证。

改主意条件
- 出现 X 时，重新评估。

来源
- 《高性价比人生指南》第 X 节第 Y 条（...）
- 当前官方来源 ...
```

## Deep

适合买房、辞职、创业、婚育、出国、重大职业转换等高影响决策。

必须包含：

1. **决策定义**
   - 选项。
   - 时间窗。
   - 关键约束。
   - 不可接受结果。

2. **证据层**
   - 最相关指南条目。
   - 当前核验事实。
   - 争议、适用范围和数据日期。

3. **分项比较**
   - 钱。
   - 时间与精力。
   - 健康/寿命。
   - 人身自由与法律风险。
   - 关系与责任，仅作为用户情境，不冒充指南统一评分。
   - 可逆性。
   - 尾部风险。
   - 选择权。

4. **条件结论**
   - 哪些条件下选 A。
   - 哪些条件下选 B。
   - 哪些条件下应该先不选。

5. **最小下一步**
   - 优先是能减少不确定性的低成本动作。

6. **退出条件**
   - 明确何时停止、撤回或重新评估。

7. **未知项**
   - 没有证据就写未知，不填空。

## 表达要求

- 先结论，后证据。
- 口语化，但不把严肃风险说轻。
- 不堆术语。
- 不使用“绝对正确”“保证”“一定会”等过度确定表达。
- 不用虚假数字增加权威感。
- 用户可以不采纳建议，不进行说教或追逼。
