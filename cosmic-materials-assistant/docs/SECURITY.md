# 安全、隐私、许可与第三方分发

- 默认在本地处理客户输入，不自行上传需求文件、工作簿或密钥到GitHub、MCP服务、云端模型。
- Agent的普通工具接口仅生成候选，不获取人工审核密钥。MCP通过 `COSMIC_MCP_ROOT` 授权单个工作目录，拒绝读取或写入目录外文件。
- 不验证人类的真实法律身份；HMAC签名只证明特定密钥对当前行和来源摘要的完整性。审核人员需要自己保管密钥与来源证据。
- 输入数据和输出文件不会覆盖同名已有数据；空行、重复表头和可疑Excel公式按防伪造策略处理。
- 文档一律禁止自动将缺失数据补齐成已批准 CFP，也不能在客户要求不适用时擅自重写其业务真实事实。
- **本目录**的 `.gitignore` 过滤用户源文件、PDF/DOCX/XLSX、artifacts和packages。当前公开的 `skills/cosmic-materials-assistant/` 来自经审核的通用发行清单；历史客户项目留在另外的私有开发仓库，不可把完整私有历史合并到公开仓库。
- MIT许可证用于该项目原创代码与原创文档，保留原许可声明；第三方规范PDF、商标和客户材料不在再授权范围内。请勿称产品受官方 COSMIC 授权或认证。
- 若在 GitHub 同步**完整本地Git历史**，必须先确保仓库为 PRIVATE。公开产品应只使用curated ZIP或干净独立的公开代码仓库。
